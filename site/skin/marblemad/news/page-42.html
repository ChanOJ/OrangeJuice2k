 Demonews Express [01 Apr 2000]
The Demonews Express is a facility which allows the user to 'walk by' the most active demoscene news and review sites. In fact all it does is display a bar at the top of your browser window with Next and Previous buttons, which make the user jump the the next site in the list when he clicks them. It is a simple client-side Javascript proggie I wrote mainly for myself so that I wouldn't have to type every URL of sites i find interesting every time, but i figured other people might as well like it. Comments are always welcome.
(Eggbird / Green)

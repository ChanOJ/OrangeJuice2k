 Mlib release [11 Jan 2000]
The goal of this library is to provide a portable and easy to use library to make a demo or any application that work on every computer and every classic operating system. This library handles video, keyboard, files, sound, memory, etc...
It works on Windows, linux, unix and DOS using always the same interface. If your application use mlib and is portable, it will work on other system.
(Ace / Melting Pot)

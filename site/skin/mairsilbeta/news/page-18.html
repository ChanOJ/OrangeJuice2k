OpenGL Extension database online
14 Aug 2000

For every democoder around who thinks OpenGL is THE api to code with, Druid- has placed a new version of his OpenGL Extension database online at:
http://www.gamedev.net/opengl/extDB.html
There you'll find all common consumer extensions, what they do, how to use them, where to find more information and which cards support the extensions. This is extremely useful for starting OpenGL coders who tend to use card specific extensions and don't realise there are more supported equivalents around. Check it out.

New OpenGL Challenge code pack [02 Aug 2000]

subject: New OpenGL Challenge code pack helps coders get started



-----------------
The OpenGL Challenge is has released the NEW Challenge Pack of handy
coding routines. If you're a programmer and interested in writing
something using OpenGL, you can get quickly started with clean,
documented, easy-to-use fully free source code. Start with this code to
create your entry for this week's theme: Free Style. Create wacky new
tunnels, particle systems, squishy object loaders, or anything your mind
can whip up using OpenGL.There are now over 105 challenge entries, which
generate awesome visual effects on your OpenGL accelerator card. Just
download, and run.

Update: URARFileLib v0.3.1 [07 Sep 2000]
The URARFileLib is a simple static library that allows you to get files from RAR archives (created with RAR or WinRAR) with one line of code. All decompression techniques including multimedia decompression and decryption are supported. For Win32, Linux and SunOS. Only 8kB (5kB UPX-compressed) small!
The new version of the UniquE RAR File Library now calculates CRC32 correctly, avoids a buffer overflow when handling corrupt archives, can handle paths in Win32 and Unix on all systems, and general code cleanups.
